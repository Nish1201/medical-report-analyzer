
# HealthLens – Medical Report Analyzer

## About the Project
HealthLens is an AI-powered medical report analysis web application designed to help users understand their medical reports in simple language. It aims to extract important information from uploaded reports, explain medical terms, and present relevant health information in an easy-to-understand format.

## Problem Statement
Medical reports often contain complex medical terminology and technical values that may be difficult for ordinary users to understand. HealthLens aims to make medical report information easier to read and understand through AI-assisted explanations.

## Key Features
- **Medical Report Upload:** Upload medical reports for analysis.
- **Text Extraction:** Extract readable text from supported medical reports.
- **AI-Powered Explanations:** Provide simple explanations of medical terms and report findings.
- **Report Summary:** Present important information in an organized format.
- **Medical History:** Support maintaining a history of previously analyzed reports.
- **Health Trends:** Help users review changes in available report values over time, where supported.

*Note: Features are subject to implementation and testing.*

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd <project-folder>
   ```

3. Create and activate a virtual environment if required.

4. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

5. Configure the required environment variables and database settings.

6. Start the backend using the entry-point file configured in the project.

7. Open the frontend using the project's configured development server or instructions.
